# Laptop and Account Security

## Device encryption

All company laptops must use full-disk encryption (FileVault on macOS, BitLocker on Windows). IT verifies the encryption status automatically every day.

## Passwords

Use the company password manager to generate a unique password of at least 16 characters for each account. Never reuse a work password on a personal site.

## Multi-factor authentication

Multi-factor authentication (MFA) is mandatory for email, source control, and the cloud console. Hardware security keys are preferred; SMS codes are not allowed.

## Lost or stolen devices

Report a lost or stolen laptop to the security team within 24 hours, even if you think it is locked. The security team will wipe the device remotely and revoke its certificates.

## Software updates

Operating system updates must be installed within 14 days of release. Laptops that fall behind lose access to internal systems until they are updated.
